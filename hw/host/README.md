# Host side

Two ways to drive the SPU on the VHK158 (both use `sw/spuc/runtime.py`):

| path | block design | Linux side | Python device |
|------|--------------|------------|---------------|
| PS (recommended first) | `bd_ps.tcl` | PetaLinux on the A72s, `spu-uio.dtsi`, u-dma-buf | `UioDevice()` |
| PCIe host | see `bd_pcie_notes.md` | AMD XDMA/QDMA driver (`dma_ip_drivers`) | `XdmaDevice(mem_base=<HBM base>)` |

Smoke test (either path):

```python
from spuc.runtime import get_device
d = get_device("uio")                 # or get_device("xdma", mem_base=0x4000000000)
print(hex(d.reg_read(0x20)))          # 0x53505531 == "SPU1"
```

then run any example with the device name, e.g. `python3 sw/examples/03_kb_rules.py uio`.

`spu_regs.h` (generated by `scripts/gen_headers.py`) carries the same register
map for C/C++ drivers.
