# 符号主义模型如何映射到 SPU

SPU 选择 **向量符号架构（VSA，Vector Symbolic Architecture）/ 超维计算（HDC）** 作为符号计算的物理载体：每个符号是一个 D=8192 bit 的随机超向量，符号之间的结构通过三种代数运算表达，推理通过解绑 + 关联记忆完成。这一框架有明确的符号语义（离散符号、角色-填充结构、可组合、可解释），同时全部运算是位并行、局部、无乘法的，是 FPGA 上最高效的符号计算形式。

| 符号操作 | VSA 运算 | SPU 指令 |
|----------|----------|----------|
| 原子符号 | 随机 HV | `HGEN`（种子 = 符号 id） |
| 角色-填充绑定 `role:filler`、关系元组 | XOR 绑定 | `HXOR` |
| 集合 / 记录 / 多个事实叠加 | 多数表决捆绑 | `ACC.CLR/ADD/THR` |
| 序列位置 / 顺序 | 置换 ρ^k | `HROT` |
| 取出成分（"USA 的货币是？"） | 解绑 + 清理记忆 | `HXOR` + `HSEARCH` |
| 相似 / 类比 / 分类 | 汉明距离最近邻 | `HDIST`, `HSEARCH` |
| 学习（原型、知识记忆） | 累加 + 二值化、感知机修正 | `ACC.ADD/SUB/THR` |

## 1. 分类模型（`frontends/hdc.py`）

* **记录编码**：`h(x) = maj_f( ID_f ⊗ L(x_f) )`，`ID_f` 是特征符号，`L(v) = L0 ⊗ MASK(v·step)` 是线性等级向量（相邻等级只差 `step` 位，最远等级近似正交）。
* **n-gram 序列编码**：`h(x) = maj_t( ρ²(S[x_t]) ⊗ ρ(S[x_{t+1}]) ⊗ S[x_{t+2}] )`，用于文本 / 符号序列。
* **训练**：第一遍把每个样本的编码加进其类别的累加器；之后每个 epoch 在设备上做最近原型预测，误分类时 `ACC.ADD 真类` / `ACC.SUB 误类`，epoch 末重新二值化（OnlineHD / 再训练式 HDC）。
* **推理**：编码 → `HSEARCH` 原型表 → 类别索引与距离。
* 整个训练循环（含样本循环、特征循环、类别选择、再训练分支）是一个约 200 条指令的 SPU 程序；`train_ref` 是比特精确的主机参考，`tests/test_hdc.py` 验证两者完全一致。

## 2. 知识库与规则推理（`frontends/logic.py`）

* **事实** `rel(a0, …, an-1)` 编码为 `maj(REL⊗ARG0⊗A0, …, REL⊗ARGn-1⊗An-1, REL⊗TAG)`，存入事实表（每行一个 HV）。
* **模式查询** `parent(alice, ?Y)`：用一个已绑定成分 `REL⊗ARG0⊗ALICE` 对事实表 `HSEARCH.WD`，匹配事实距离 ≈ D/4、无关事实 ≈ D/2（阈值由多数表决理论值计算：k 路多数与其成分一致概率 p_k，阈值 = 中点）；对候选事实逐个解绑校验其余已绑定成分，再解绑 + 清理记忆取出未绑定变量。
* **Horn 规则**：`grandparent(X,Z) :- parent(X,Y), parent(Y,Z)` 编译成嵌套的模式求值（体原子从左到右，变量绑定通过标量索引 + HV 寄存器传递，支持 `Neq` 内建）。头部事实在设备上编码、与事实表搜索去重（重复事实距离为 0，阈值 D/8），追加到事实表，并记录 `(关系, 参数…)` 行给主机解码。
* **前向链接 / 不动点**：多轮应用所有规则，直到某一轮不再产生新事实（`break_`），支持递归规则（祖先、区域传递闭包）。`evaluate_ref` 是朴素 Datalog 求值器，`tests/test_logic.py` 验证设备推出的事实集合与之相同。

## 3. 类比推理（`examples/01_analogy.py`）

经典的 "What is the dollar of Mexico?"：`USA = maj(NAME⊗USA, CUR⊗DOLLAR, CAP⊗DC)`，`DOLLAR ⊗ USA ⊗ MEXICO` 清理后得到 `PESO`。SPU 程序 48 条指令。

## 4. 结构分解 / 解析（`examples/05_resonator.py`）

共振器（resonator）式因子分解：已知 `S = X_i ⊗ Y_j ⊗ Z_k`，从三个码本的叠加估计出发，迭代 `x ← cleanup_X(S ⊗ y ⊗ z)` 等，几轮内恢复 `(i, j, k)`（3×24 个符号、13824 种组合，2 轮收敛）。这是 VSA 中"解析"复合符号结构的基本算法，循环、绑定、清理、收敛判断全部在设备上完成。

## 噪声余量

D=8192 时随机向量间距离的标准差约 45 bit，而各种"信号"间距是 1000-2000 bit 量级（3 路多数的成分相似度 0.75 → 距离 2048；两次解绑级联后仍约 3072 vs 4096），因此清理与阈值判断的错误率在实际规模下可以忽略；需要更多叠加 / 更深链式推理时把 `Config.D` 调到 16384 即可（编译器、模拟器、RTL 均参数化）。

## 扩展方向

* 整数 / 双极 HV（点积相似度）：在 `spu_search` 增加 MAC 模式。
* 共振网络（resonator）分解：已有原语即可，编译器循环发射 `HXOR + HSEARCH`。
* 更多类别 / 累加器：把类原型累加器换成内存驻留（`ACC.LD/ST` 轮换）。
* Datalog 引擎的哈希连接单元：作为 HSEARCH 之外的第二类关联单元。
